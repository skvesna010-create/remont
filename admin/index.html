Админка лендинга

Все изменения сохраняются в репозиторий GitHub, и лендинг remont.domilia.ru обновляется сам через 1–2 минуты.

Как получить ключ (2 минуты)
  1. Откройте GitHub → Settings → Fine-grained tokens → Generate new token.
  2. Token name: domilia-admin. Expiration: 1 год.
  3. Repository access: Only select repositories → выберите remont (можно сразу и smaltera — тогда этот же ключ подойдёт и для админки основного сайта).
  4. Repository permissions → Contents: Read and write.
  5. Нажмите Generate token, скопируйте ключ и вставьте сюда.

Ключ хранится только в этом браузере. Никому его не передавайте.
